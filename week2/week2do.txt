階段,重點任務,預計時間,為什麼先做這個？
1,徹底搞懂「什麼是 file descriptor」,今天～明天,這是所有後續概念的共同語言
2,自己打出 copy.c 並跑通 + 改幾個小地方,1–2 天,親手操作 read/write 循環最有感
3,理解 copy.c 為什麼要「檢查 write 的回傳值」,第 2–3 天,這是真實程式最常出錯的地方
4,把 copy.c 改成「只讀不寫」或「只寫固定內容」的小變形,第 3 天,確認你真的懂 read 和 write 分開在幹嘛
5,接下來再碰 dup2 / dup / lseek,第 4–5 天,建立在 fd 和 read/write 都懂的基礎上
